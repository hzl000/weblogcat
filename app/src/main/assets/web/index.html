支持 package / process / tag / message / line / pid / tid / uid / level / age / is:crash / is:stacktrace / name。排除加 -，正则加 ~，包含空格或运算符的值请加引号。& 优先于 |；相同字段的正向条件默认 OR，其余默认 AND。普通文字搜索消息，默认区分大小写。

应用多选作为额外范围条件；package:mine 指当前选中应用。进程信息缺失时显示未知，不将共享 UID 强行分配给某个包。暂停仅冻结显示，清空仅影响当前页面。最多缓存 5 万条 / 32 MB，超限淘汰旧日志。堆栈按相邻同进程、线程、标签及时间启发式归组，命中一行保留整组。
