# WebLogcat 产品需求草案

状态：用户已回复“按推荐全部做”。本文件保留确认时的建议范围，最终操作语义见 filtering.md。

## 已明确提出的目标

- APK 支持全面屏适配。
- 服务启动后显示二维码，供其他设备扫码访问。
- 支持自定义 HTTP 端口。
- 网页支持浅色、深色模式切换。
- 网页应用列表显示名称、包名、图标，支持按应用筛选日志。
- 日志过滤体验接近 Android Studio Logcat，已确认的核心范围见 filtering.md。

## 建议的过滤范围

- 普通文本、带引号的短语。
- package、process、tag、message、line、pid、tid 字段。
- level 指定最低等级；等级选择器作为查询之外的额外最低等级条件。
- 排除条件、正则、AND/OR、括号；同键正向条件隐式 OR，其他条件隐式 AND。
- age、is:crash、is:stacktrace。
- 语法错误提示、补全、历史、收藏。
- 第一版暂不包含 IDE 源码跳转、多窗格比较。

参考：https://developer.android.com/studio/debug/logcat

## 必须明确的产品语义

1. 是否接受上述全部过滤范围，是否要求直接粘贴 Android Studio 查询即兼容。
2. 应用列表默认用户应用，可选系统应用；支持多选、多个进程、进程重启后跟踪。无法明确归属的日志显示未知。
3. package:mine 建议代表当前选择的应用，未选择时给出提示。这与 IDE 当前项目的含义不同，需要明确接受。
4. 建议持续采集，筛选仅改变浏览器视图；各浏览器的条件独立。
5. 建议内存缓存以 5 万条或 32 MB 为上限，先到先淘汰；默认不写磁盘。支持导出过滤结果及全部缓存。
6. 建议暂停仅冻结画面，清空仅清当前浏览器视图，不清系统日志。
7. 建议异常堆栈作为组显示，命中其中一行时保留整组，并支持查看上下文。
8. 需要确定普通文本的搜索字段和大小写规则；建议默认消息内容、区分大小写，提供忽略大小写开关。正则引擎和兼容边界需在实现时明确并测试。

## 其余建议默认值

- 全面屏采用 edge-to-edge，保留系统栏，适配安全区域、挖孔和手势导航。
- 默认端口 8765，持久化配置；占用或非法端口显示错误。修改端口只重启 HTTP 监听，保持日志采集会话。
- 仅在监听成功后显示包含实际 IP、端口、token 的二维码，提供复制链接；网络变化后更新地址。
- 网页支持浅色、深色、跟随系统，持久化主题，适配手机和电脑。
- age 按手机时间计算，避免浏览器所在设备的时钟差异。
- 不承诺系统杀进程后静默恢复全日志读取；已有实测表明需要前台系统确认。

## 验证步骤

- 查询解析器以独立用例覆盖逻辑优先级、隐式条件、转义、非法输入及正则。
- 应用归属验证多进程、重启、共享 UID、未知进程，避免把 UID 直接当作唯一包名。
- 缓存和网页验证持续高日志量、暂停、回看、多客户端及导出范围。
- 实机验证系统栏适配、端口修改、二维码扫码、主题切换、应用图标及筛选。
